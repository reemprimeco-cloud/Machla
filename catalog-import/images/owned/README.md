# Owner-supplied photography

Product photographs the project owner holds **full rights to** — their
own camera, or bought outright with no redistribution restriction. That
is the entire reason these are committed while the images one directory
up are not (`../.gitignore`): publishing them needs nobody else's
permission.

If an image here later turns out to be licensed stock rather than owned
outright, move it up one directory. It will still be found and uploaded
exactly the same way; it just stops being published in a public repo.

## Naming

Named after the **product type**, same namespace as `../generated/` and
the directory above. A file here overrides generated artwork of the same
name — which is the intended path for replacing generated images with
real photographs over time.
